# Shopee Video Downloader

Download video produk Shopee tanpa watermark secara gratis.

## Fitur
- Download video produk Shopee
- Tanpa watermark
- Gratis tanpa batas
- Tanpa perlu install aplikasi

## Setup

```bash
npm install
npm run dev
```

## Environment Variables

Salin `.env.example` ke `.env.local` dan isi sesuai kebutuhan.

## Deploy

Deploy ke Vercel:
```bash
npx vercel
```
